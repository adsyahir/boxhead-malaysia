Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## HIGH (Hard Gate)

1. **R-02 Em dash in UI text.** `apps/web/game3d/ui/Screens.tsx:321` prints `—` in the How to Play weapon list for the free weapon. Fix: replace it with a word ("Dari awal" / "From the start") via a new string key.

2. **R-32 Keyboard focus indicator removed and replaced by a background change that is too faint.** `.g3d-btn:focus-visible` (every menu, lobby and pause button) and `.lang-switch button:focus-visible` set `outline: none` and only shift the fill from `#1c2640` to `#3a5088`. Measured contrast between those two fills is **1.92:1**, below the 3:1 needed for a focus indicator. Chips, cards, inputs and hero options are fine (their focus changes the border to the accent, 12.7:1). Fix: a 3px accent `outline` with offset on `:focus-visible` for buttons and the language switch.

3. **R-37 No design direction on record.** There is no `DESIGN.md` or brand brief. Palette (navy + yellow), the all-monospace type and the voxel look were chosen by the assistant, not the owner, so by the rule this UI is a draft until direction exists. Fix, owner's choice: (a) write a short `DESIGN.md` yourself (identity, palette, type, mood, dials), (b) tell me the direction and I transcribe it, or (c) accept the draft label. Also resolves the "written reason" requirement of R-31 for #9 and #11.

4. **R-03 Tap targets below 44px.** By CSS arithmetic (padding + line height + border, not measured on a device): `.g3d-chip` about 34px, `.lang-switch button` about 30px, `.g3d-back` about 36px. These are the Online screen's Join and Refresh chips, the Lobby's Copy, map and Leave controls, and the language switch, which is the audience that uses Online on phones. Fix: `min-height: 44px` (and min width) on touch devices for those controls.

5. **R-25 Component borders fail non-text contrast.** The standard border `#41598f` is **2.66:1** against panels (`#0e1426`) and 2.82:1 against the page; inputs, chips, cards and buttons rely on it as their edge. Needs 3:1. Fix: lighten the border token (for example toward `#5f7cbf`), re-run the checker, and re-check hover states.

6. **R-24 Menu items lead to a page that does not exist yet.** "Papan Markah" is a primary item on the main menu and a button on Game over (offline), but the page only says "coming soon". The destination is honest; the entry is not labelled. Fix: label the entries "(akan datang)" / "(coming soon)" and disable them, or remove them until the leaderboard exists.

7. **R-23 / R-38 Unconfirmed name in Credits.** The Credits screen says "Dibuat oleh adsyahir". That name came from the git handle, not from the owner. Fix: owner confirms the credit line (or says to remove it).

8. **R-35 Click-through evidence has gaps.** Verified so far: menu flow, language switch, settings, pause menu, exit confirm, online create/join/ready/start/move (9 passing browser tests, plus a manual run). Not clicked: Copy code, Copy link, Refresh rooms, map chips in the lobby, lobby Leave, hero options in the lobby, Credits and How to Play on the touch layout, and Tab-only navigation of any screen. Fix: I click through these and report each element.

## MEDIUM (Purpose-Gate)

9. **R-06 Everything is set in monospace.** `font-family: ui-monospace, "SF Mono", Menlo, Consolas, monospace` for all text, including the paragraphs on How to Play and the lobby notes at 0.8rem. No written reason. Monospace fits the arcade title; it hurts reading of longer text. Fix: keep it for titles, numbers and codes (reason: arcade identity, room codes read letter by letter) and use a readable sans for paragraphs, or write the reason down if you want to keep it everywhere.

10. **R-04 Emoji and symbol glyphs used as icons.** Mute buttons use 🔇 / 🔊 (`Game3D.tsx:563`, `Hud.tsx:70`, Phaser `hud.ts:53`), the exit button uses ⌂, pause uses ❚❚. Emoji look different on every OS and read as AI decoration; "Shift ›" in the controls table is unclear. Fix: small inline SVG icons (each with its label), and write "Right Shift" / "Shift Kanan".

11. **R-10 Blur on too many surfaces.** `backdrop-filter: blur(5px)` is on `.g3d-btn`, `.g3d-card` and `.g3d-panel` at once; on hero select that is eight cards plus buttons. Cap is 1 to 2 elements. Fix: keep the blur on the panels only; make buttons and cards solid.

12. **R-27 Weak error and loading states.** (a) The server errors `not_host`, `not_ready` and `bad_message` all show "Sesuatu tidak kena. Cuba lagi." which names no cause or next step. (b) While a room is being created or joined the buttons just disable; no "Menyambung..." text appears. Fix: specific strings for each case, and a visible connecting line when `busy`.

## LOW (Quality Locks)

13. **R-32 Overlays and HUD buttons.** The three HUD corner buttons are `tabIndex={-1}` (keyboard equivalents exist: P/Esc, M), and the pause, in-game Help and Settings overlays do not move focus into themselves or use `role="dialog"`. Fix: give overlays `role="dialog"` + `aria-modal`, focus the first control on open, restore focus on close. Keep the HUD buttons out of the tab order only if you want Tab never to steal game focus (say so and I note the reason).

14. **R-25 Input placeholder contrast.** The "KOD" placeholder uses the browser default (`#757575`), **3.81:1** on the input fill `#101830`. Fix: set the placeholder color to the muted text token (6.5:1).

15. **R-20 / consistency: `/play2d` ignores the language setting.** The Phaser 2D version's menus are hard-coded Malay (only its HUD toasts follow the language). Fix: translate its few strings through `t()`, or label that page Malay-only.

## Checked and clean

- Text contrast: all text pairs measured pass AA (lowest 5.33:1, the muted text on card fill). Accent button text 12.0:1.
- R-01/R-13/R-19: no default gradients (only a legibility vignette), glow limited to the game-over title, no endless animations.
- R-15/R-16: no generic CTAs or buzzwords in either language; room actions are specific ("Cipta bilik awam", "Create public room").
- R-17/R-18/R-36: no statistics, testimonials or trust claims; player counts like "1/2" are real.
- R-09/R-11: the only pill is the seat status tag, which marks a real state.
- R-27 (rooms list): loading, empty and server-unreachable states all exist and say what is happening.
- R-34: one theme, fixed dark, which fits a night game (reason: setting).
- Copy scan (Malay and English): no empty AI vocabulary, no significance inflation, no fake-candid openers, no signposting, no chatbot closers.
- Language: `<html lang>` follows the setting; the language switch is labelled and pressed-state aware.
